WOVEN ROD TRAY v1 — 2-colour Bambu P2S print (Oct 13 2026, rebuilt on the v2 design at v1 size)
=====================================================================================
What it is: a 117 x 117 x 33 mm rounded-square block of stacked round rods with a 94 mm spherical dish dipped
into the top (22 mm deep). Nothing on it is square: 20 mm plan corners, round rods (1.68 x 0.80 beads with
rounded ends) and a pillowed top edge (6 mm radius). The bottom is straight and full-size: a flat print, no
course ever reaches past the one beneath it, nothing overhangs. The weave runs straight with the block,
and alternate courses of each axis skip every 4th rod with the gap
drifting one rod per repeat: a faint twill diagonal across the walls and the dish floor.
X rods = filament 1 (rust), Y rods = filament 2 (cream); the top course and the dish floor are rust.
No supports, no infill, no brim.

Open woven_tray_2color.3mf in Bambu Studio. It is a project: P2S 0.4 nozzle, 0.20 mm layers, ONE object
"woven tray" with two parts — "rust rods" on filament 1 and "cream rods" on filament 2. The bed is set to the
real 256 x 256 and the prime tower is parked back-right (216, 216), clear of the object at 69..187.
  1. Map AMS slot 1 -> rust/terracotta PLA, slot 2 -> cream/bone PLA. Matte PLA reads as textile; avoid silk.
  2. Check the object list shows the cream part on filament 2 (if it shows 1, click the part, pick 2).
  3. Slice, print. Prime tower is on — needed: the colour flips every 4 layers (every 0.8 mm course).

Numbers (Bambu Studio CLI 2.8.2, single-colour pass — the CLI cannot see part->filament assignment):
  4h 53m model time, 126 g, 164 layers. Add the swaps: 40 colour changes x ~45 s plus purge (~12 g),
  so expect ~5.5 h and ~140 g in the GUI estimate.

Settings baked in (same as v1): layer 0.20 · 4 wall loops · 0% infill · 0 top/bottom shells · thin-wall ON
  arachne · line width 0.42 · overhang 4/4 + totally 50, bridge 50, outer 100 / inner 150, first layer 35
  seam aligned · elephant-foot 0 · no brim.
Bed: the first course is the full footprint — round rust rods directly on clean PEI (IPA), about 1.1 mm of
  contact per rod. Glue stick optional.
  Let it cool fully before lifting.

Fallback without the 3MF: import woven_tray_rust.stl AND woven_tray_cream.stl together, answer YES to
  "load as a single object with multiple parts", set the cream part to filament 2, apply the settings above.

Tweak (woven_tray_v1.py in ~/Dev/text2print, run with .venv/bin/python):
  size 117 / height 33 / floor_t 10.4 / dip_d 94 / corner_r 20
  ease_top_r 6, ease_bot_r 0      — top pillow; ease_bot_r > 0 would round the bottom (dropped: flat print)
  weave_deg 0                     — 45 gives a diagonal weave (tried, dropped)
  twill_skip 4                    — 0 turns the twill off (uniform mesh); 3 is bolder
  pitch 3.6, rod_lines 4, rod_layers 4 — rod spacing / section (rod_layers also = swap cadence)
The 160 mm platter version (same design, bigger and flatter) is in ../v2.
